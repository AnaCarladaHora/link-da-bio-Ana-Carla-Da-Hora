# 🔗 Link da Bio — Ana Carla Da Hora

> Uma landing page pessoal desenvolvida para centralizar minha presença profissional, projetos e principais canais de contato em um único endereço.

## 💻 Sobre o projeto

O **Link da Bio Ana Carla Da Hora** foi desenvolvido como uma página pessoal responsiva, com foco em **identidade profissional, experiência do usuário e acessibilidade aos meus principais canais digitais**.

A proposta surgiu da necessidade de ter um espaço simples e elegante para apresentar minha trajetória na área de Tecnologia da Informação e direcionar visitantes para meu **portfólio, GitHub, LinkedIn, projetos e redes sociais**.

Além de funcionar como uma página de links, o projeto também representa uma aplicação prática dos meus conhecimentos em **desenvolvimento web, organização de interfaces e experiência do usuário**.

---

## 🎯 Objetivos

* Criar uma apresentação profissional para utilização em redes sociais;
* Centralizar meus principais links profissionais;
* Facilitar o acesso ao meu portfólio e projetos;
* Aplicar conceitos de desenvolvimento Front-End;
* Criar uma interface responsiva para diferentes dispositivos;
* Desenvolver uma experiência visual alinhada à minha identidade profissional.

---

## 🛠️ Tecnologias utilizadas

### Front-End

* **HTML5** — estrutura semântica da aplicação;
* **CSS3** — estilização, responsividade, animações e identidade visual;
* **JavaScript** — interações e funcionalidades da página.

### Recursos utilizados

* Google Fonts;
* CSS Variables;
* CSS Grid/Flexbox;
* Responsive Design;
* LocalStorage;
* Intersection Observer API;
* Git & GitHub;
* GitHub Pages.

## ✨ Funcionalidades

### 🌗 Dark Mode

A página possui um sistema de alternância entre **modo claro e modo escuro**.

A preferência do usuário é armazenada utilizando `localStorage`, permitindo que o tema escolhido seja mantido durante novas visitas.

### 📱 Design Responsivo

A interface foi desenvolvida utilizando princípios de **Responsive Web Design**, permitindo sua utilização em:

* 📱 Smartphones
* 📲 Tablets
* 💻 Notebooks
* 🖥️ Desktops

### 🎞️ Animações

Os cards de links possuem animações de entrada utilizando a **Intersection Observer API**, criando uma experiência mais dinâmica sem depender de bibliotecas externas.

### 🔗 Links profissionais

A página centraliza:

* 💼 Portfólio
* 💻 GitHub
* 👩🏾‍💻 LinkedIn
* 📚 Ana Carla Books
* 📱 Instagram
* ▶️ YouTube
* ✉️ E-mail profissional

## 🧩 Estrutura do projeto

```text
link-bio-ana-carla/
│
├── index.html
├── style.css
├── script.js
│
└── img/
    └── ana-carla.jpg
```

### `index.html`

Responsável pela estrutura e organização dos elementos da página.

### `style.css`

Responsável pela identidade visual, responsividade, componentes, estados de interação e Dark Mode.

### `script.js`

Responsável pelas interações da aplicação, incluindo:

* Alternância de tema;
* Persistência do tema com LocalStorage;
* Animações de entrada;
* Atualização automática do ano no rodapé;
* Interações dos cards.

## 🚀 Como executar o projeto

### 1. Clone o repositório

```bash
git clone https://github.com/AnaCarladaHora/link-bio-ana-carla.git
```

### 2. Entre na pasta

```bash
cd link-bio-ana-carla
```

### 3. Abra o projeto

Abra o arquivo:

```text
index.html
```

diretamente no navegador.

Não é necessário instalar dependências ou utilizar um servidor para executar a versão básica do projeto.
